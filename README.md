## Engineering Identity

I’m most interested in systems that sit between **cloud infrastructure and the physical world**.

That means I’m equally comfortable thinking about AWS architecture, Linux servers, networking, containers and CI/CD — then moving down the stack into embedded systems, robotics, sensors, RFID, and automation.

**The pattern in my work:**

`connect → automate → observe → improve`

- Cloud infrastructure and AWS environments
- Linux / Windows systems and networking
- Docker, Kubernetes and deployment pipelines
- Infrastructure as Code with Terraform
- Home-lab and self-hosted infrastructure
- Robotics, IoT and embedded systems
- AI-assisted automation
- Growing deeper into Cloud Security / DevSecOps
